What is this, in plain words

UAV drones fly for hours on piston engines. If the engine has a hidden problem, it can fail mid-flight. A digital twin is a virtual copy of the engine, running in software, constantly fed sensor data (temperature, vibration, pressure). It predicts failures before they happen, instead of after.

This page shows two things: a replay of real historical engine data so you can see how the prediction changes as an engine ages, and a live predictor where you can type in sensor readings (or upload a file of them) and get a real prediction from the trained model, running on a live server.

Key terms explained

RUL — Remaining Useful Life
How many more operating cycles the engine is expected to run before it would fail. Predicted in cycles, capped at 130 here (beyond that, "healthy" is healthy enough not to need a precise number).
Digital twin
A virtual, software-based copy of a real machine, kept in sync with real sensor data, used to monitor and predict its condition without waiting for it to actually break.
Health status
Healthy = plenty of life left. Warning = degradation detected, plan maintenance. Critical = failure risk is high, act now.
MAE — Mean Absolute Error
The average size of the model's prediction mistakes. An MAE of 13 cycles means predictions are typically off by about 13 cycles, in either direction.
Rolling features
Instead of judging an engine from a single instant, the model looks at the recent trend (e.g. average of the last 5 readings) — this smooths out noise and catches gradual degradation.
Why turbofan data?
Real piston-engine UAV sensor data isn't publicly available (defense-restricted). This prototype is validated on NASA's public turbofan degradation dataset — the standard benchmark for this exact ML problem — and the same pipeline would apply to real piston-engine telemetry.
